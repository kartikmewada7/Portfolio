## 💻 Interactive Developer Terminal (CLI)
Click the **Terminal [CLI]** button or press the terminal icon in the navbar.
Commands available:
- `help` — List all commands
- `projects` — Display projects with clickable links
- `certs` — View certificates with verification links
- `skills` — View skill competency bars
- `about` — Developer bio
- `contact` — Email, GitHub, and LinkedIn links
- `theme [cyber | synthwave | matrix | gold]` — Switch theme live
- `cat resume` — View quick CV overview
- `clear` — Clear terminal screen
